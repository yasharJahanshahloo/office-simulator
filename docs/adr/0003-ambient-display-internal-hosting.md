# ADR-0003: Ambient display, internal hosting

Status: accepted (2026-10-31)

## Decision
- v1 is an **ambient display**: office TV + browser tab showing who is working with AI right now.
- Team-level gamification may come later; **no per-person usage reports** for management.
- Hosted on an internal server reachable over VPN; **no auth in v1**. Add company SSO only if it must be exposed outside.
